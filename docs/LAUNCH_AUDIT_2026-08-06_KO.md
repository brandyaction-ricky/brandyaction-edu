# 브랜디액션 에듀 런칭 기능 감사

감사 기준일: 2026-08-06
상태 표기: `[x]` 소스 구현·정적 검증 완료, `[ ]` 외부 운영 환경에서 추가 확인 필요

## 감사에서 발견한 핵심 문제

- 결제 화면의 상품명·기수·금액이 고정돼 있었고 PG 승인 없이 완료 화면으로 이동했습니다.
- 결제 완료와 수강권 발급이 연결되지 않았습니다.
- 모든 수강권이 같은 고정 학습 화면으로 이동했고 VOD·자료·진도가 DB와 연결되지 않았습니다.
- 관리자 회원·주문·리뷰 화면과 대시보드가 샘플 데이터 또는 브라우저 저장소를 사용했습니다.
- 스태프 권한 설정은 저장만 되고 API·RLS에서 집행되지 않았습니다.
- 공개 후기·성과 수치·상품 시드가 임시 데이터였습니다.
- 결제 웹훅 실패 이벤트가 재시도되지 않았고 중복 결제창이 정원을 중복 점유할 수 있었습니다.
- 수강권 종료일이 기수 운영 종료일과 연결되지 않았고 정지 회원의 기존 세션 접근이 차단되지 않았습니다.

## 런칭 차단 외부 항목

1. 현재 로컬 환경에는 Supabase 공개키·서비스 역할 키와 Toss 키가 없어 실제 DB·PG E2E 테스트를 실행할 수 없습니다.
2. 운영 DB 마이그레이션은 데이터에 영향을 주므로 백업과 명시 승인 후 적용해야 합니다.
3. Vercel CLI 로그인 세션이 없어 운영 프로젝트 환경변수를 내려받거나 Preview 배포할 수 없습니다.
4. Toss 운영 계약·결제수단 심사, 웹훅 등록과 키 발급은 운영자 계정에서 완료해야 합니다.
5. 통신판매업 신고번호와 개인정보 국외 이전·수탁사 최종 목록은 판매 오픈 전에 정책 원문에 확정해야 합니다.
