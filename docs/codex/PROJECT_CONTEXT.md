# Project Context

## 1. 서비스 개요

- 서비스명: BrandyAction EDU
- 저장소: `brandyaction-ricky/brandyaction-edu`
- 목적: 무료 콘텐츠 유입부터 유료 교육 결제, 학습, 미션, 운영, 성과 분석까지 하나의 플랫폼에서 관리한다.
- 주요 사용자:
  - 공개 방문자
  - 일반 회원과 수강생
  - `staff` 운영자
  - `marketing` 업무 권한을 가진 운영자
  - 관리자

## 2. 핵심 사용자 흐름

### 무료클래스

```text
광고·오가닉 유입
→ 무료클래스 상세
→ CTA 및 카카오 오픈채팅
→ 방문·CTA 이벤트 수집
→ 캠페인/Meta/실측 성과 대시보드
```

무료클래스의 Landing, CTA, 트래킹, 가격 Snapshot, 실측 데이터는 마케팅 성과 분석의 기준 데이터이므로 임의 삭제하거나 재생성하지 않는다.

### 유료클래스

```text
회원 로그인
→ 상품·기수 선택
→ 서버 주문 생성
→ 쿠폰 검증 및 할인 Snapshot
→ Toss 결제 승인 또는 0원 주문 완료
→ 주문 paid
→ 수강권 발급
→ 학습·미션·질문·후기
```

주문 금액과 권한 부여는 서버 및 DB 함수가 최종 판정한다. 결제 승인 성공과 내부 완료 처리가 분리될 수 있으므로 멱등성과 재조회 경로를 보존한다.

### 관리자

- 상품, 기수, 학습 콘텐츠, 미션, 제출물, 질문 관리
- 회원, 스태프 권한, 고객 태그, 쿠폰, 주문·환불 관리
- 배너, 아티클, 후기, SEO·운영 설정
- 무료클래스 트래킹, 캠페인, Meta 실적, CSV, 실측 데이터 관리

## 3. 제품 정책

- 무료·유료·디지털 상품은 한 저장소에서 운영하되 공개 조건과 결제 흐름은 구분한다.
- 기수가 없거나 모집 가능한 기수가 아니면 유료 주문을 시작하지 않는다.
- 쿠폰 할인은 클라이언트가 아니라 DB와 서버에서 다시 계산한다.
- 결제 완료 시 주문, 결제, 수강권, 쿠폰 사용, 자동 태그의 정합성을 보장한다.
- 전액 환불 시 정책에 따라 수강권을 회수한다.
- 관리자와 staff 권한은 역할과 업무 범위를 모두 검사한다.
- Meta 광고계정은 공통 계정을 사용하며 캠페인에는 복수 Meta 캠페인 ID를 연결할 수 있다.
- Organic 데이터에는 Meta 광고비 기반 지표를 귀속하지 않는다.

## 4. 현재 중점 영역

- 결제·쿠폰 DB 정합성
- Paid·Organic 마케팅 귀속과 Meta 동기화
- 무료클래스 운영형 대시보드와 CSV 정합성
- 관리자 권한 및 작업 속도
- 학습 콘텐츠·미션·질문 운영

현재 완료·미완료 상태는 `CURRENT_STATE.md`에서 확인하고, 작업 전에 GitHub와 DEV 환경을 다시 조회한다.
