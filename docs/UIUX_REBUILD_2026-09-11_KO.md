# Brandy Edu UIUX 재개발 — DEV

## 작업 기준

최신 요청에 따라 기존 Google·Kakao 소셜 인증 연결을 유지하고 프론트, 학습, 운영 화면과 API를 재작성했다. 업로드한 brandy-edu-brand-final.zip의 Action System 스타일을 사용했다. 기존 회원·주문·상품 데이터는 삭제하지 않았다. 운영 main 및 운영 DB는 이번 작업 대상이 아니다.

## 구현

- 홈, 클래스 유형 필터·검색, 무료·유료·디지털 상세, 아티클, 고객 이야기.
- Google·Kakao 로그인, OAuth 콜백, 가입 동의, 회원 정보 수정.
- 무료 신청, 쿠폰 적용, Toss 결제 요청·승인, 주문별 결과 확인.
- 내 클래스·주문·자료·쿠폰·후기, 학습 완료, 미션 임시저장·제출·검토·피드백, 질문·답변.
- 관리자 상품·기수·주차·학습 콘텐츠·미션·고객·후기·배너·아티클 등록/수정. 리스트 검색·상태 필터·CSV.
- 이미지 직접 업로드(최대 10MB)·학습 자료 직접 업로드(최대 20MB), 아티클 본문 블록 편집. 자료는 비공개 저장소의 단기 서명 URL로 다운로드.
- 실제 모집 날짜, 수강 시작/종료 및 철회 상태, 리소스별 기본키, 로컬 날짜 입력을 반영.

## 아직 검증·구현을 구분해야 하는 항목

- 실제 소셜 계정으로 신규 가입 완료, 실제 카드 결제, 로그인된 관리자 파일 업로드 및 학습 완료→미션 승인 흐름의 실계정 E2E는 이번 자동 검증에 포함하지 않았다.
- 자동 테스트의 결제 제공자 응답은 모의 응답이며 실제 결제 성공 증거가 아니다.
- 디자인의 모든 시연 기능을 상용 완료로 선언하지 않는다. 회차별 라이브 일정 관리·기수 복제, 미션 퀴즈와 레벨 계산, 태그 자동화·메시지 발송, 운영자별 세부 권한, 환불 PG 처리, 실측 성과의 집계/트래킹은 후속 작업이다.
- 검색코드·운영·실측 메뉴의 설정 레코드 저장은 가능하지만 해당 설정을 이용한 실제 추적/보고서 자동화는 아직 연결하지 않았다.
- 목록은 최대 1,000건을 조회하며 대량 데이터 페이지네이션과 고급 일괄 작업은 후속 범위다.
- 시안 샘플 수치·후기를 실제 성과로 새로 생성하지 않았다. 기존 DB의 DEV 샘플을 포함해 저장된 공개 콘텐츠를 조회한다.

새 운영 RPC는 모두 서버 전용이며, 라이브 링크의 RLS를 동일 상품이 아닌 **정확한 기수의 활성 수강권**으로 제한했다. CRM 변경 RPC의 불필요한 일반 회원 실행 권한도 제거했다. 보안 점검에서 내부 CRM 함수의 공개 실행 경고가 제거되었고, RLS 조회 헬퍼 및 기존 설정 권고는 남아 있다.

자동 검사 20개 통과: 기존 결제·인증 회귀, 퀴즈 정답 비노출·정밀 통과 기준·잘못된 응답, 중복 제출의 성취도 계산, 설정 허용 목록, 관리자 권한·요청 출처, 일괄 검토 입력, 라이브 URL 검증, 비공개 자료의 서명 발급 경계.

남은 범위는 외부 메시지 실제 발송, PG 환불 실행, 운영자별 세부 권한, 일반 목록의 1,000건 초과 서버 페이지네이션이다. 회원 미션 보고서와 기간별 랜딩 집계는 서버에서 전체 대상에 대해 계산한다. 실계정 OAuth·유료 결제와 로그인된 운영자의 저장→학생 이용까지의 브라우저 E2E는 별도 검수가 필요하며, 자동 검사는 모의 제공자/DB를 포함한다. UI 시안의 전체 기능이 상용 완료되었다고 간주하지 않는다.

## 3차 — 남은 운영 기능 구현 (2026-09-11)

- 관리자 메뉴에 메시지 템플릿·캠페인 발송·자동 메시지·스태프 권한 화면을 추가했다.
- 스태프는 클래스·회원·주문·콘텐츠·마케팅의 5개 업무 영역을 회원별로 부여받는다. 메뉴 노출과 서버 조회·저장·업로드·환불 API가 같은 권한표를 사용하며 기본값은 전부 거부다.
- SOLAPI 공식 Node SDK를 연결하고 예약 캠페인 및 자동화 큐 실행기를 추가했다. Vercel Cron은 5분마다 큐를 확인한다. `CRM_DELIVERY_ENABLED=true`와 SOLAPI·발신번호·무료수신거부·Cron 비밀값이 준비되기 전에는 외부 발송이 실행되지 않는다.
- 마케팅 메시지는 활성 회원, 정상 휴대폰 번호, 마케팅 수신 동의를 모두 확인한다. SMS/LMS에는 광고 표기와 무료수신거부 번호를 붙이며, 알림톡은 승인 템플릿과 카카오 채널 설정을 요구한다.
- 일반 관리자 목록은 주 화면 데이터를 서버에서 100개 단위로 조회하고 전체 건수 기반 페이지 이동을 제공한다. 회원 미션·주문·성과처럼 전용 조회 화면이 있는 메뉴는 기존 전용 페이지네이션과 집계를 유지한다.
- 업로드 파일은 앱 서버 본문을 통과하지 않고 2시간 유효한 Supabase 서명 업로드 토큰으로 Storage에 직접 전송한다. 이미지 10MB, 학습 자료 20MB 제한과 확장자·이미지 헤더 검사를 적용했다.
- 자동 테스트 47개, TypeScript, ESLint 오류 0개, Next.js 프로덕션 빌드를 통과했다.

외부 권한이 필요한 잔여 검수는 SOLAPI 발신번호·카카오 템플릿 승인 후 DEV 시험번호 발송, Toss 테스트/실결제 및 환불, Google·Kakao 신규 계정 OAuth, 실제 모바일 기기 확인이다. `main`과 운영 DB에는 이번 변경을 반영하지 않는다.
