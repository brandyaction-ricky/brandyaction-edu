# 최종 UIUX 퍼블리싱에 기능 이전

## 기준과 범위

- 기준 파일: 사용자가 이번 요청에 업로드한 `brandy-edu-brand-final(2).zip`.
- `design-reference/source`에 시안 소스를 보존한다. 런타임에서는 시안 JavaScript를 실행하거나 예시 회원·통계·결제를 사용하지 않는다.
- `scripts/build-uiux-css.mjs`가 원본 토큰과 두 영역 CSS를 `.edu-front` / `.edu-admin`으로 격리해 재생성한다. `app/ui/final/integration.css`는 실제 데이터·업로드·접근성 어댑터다.
- 개발된 인증·결제·미션·운영 기능을 React 화면에 연결한다. 운영 `main`이나 운영 DB에 반영하지 않는다. 신규 DB 마이그레이션 없음.
- 아래 대응표는 구현 경로를 뜻하며, 47개 화면의 픽셀 비교 또는 실제 로그인·결제 E2E 완료를 뜻하지 않는다.

주차 구성(`/admin/weeks`), 자료 원본 편집(`/admin/contents`)은 학습 화면에서 연결한다. 스태프 권한·CRM 템플릿·캠페인·자동화는 삭제하지 않고 ‘추가 운영 도구’에 유지한다. 원본 디자인에 없는 필드는 기존 저장 기능을 잃지 않도록 어댑터로 포함한다.

## 보안·동작 보존

- Google·Kakao 콜백, 허용된 다음 주소, 필수 약관 기록을 유지한다. 시안의 가상 이메일/비밀번호 로그인은 추가하지 않는다.
- 결제 생성·승인·환불·중복 요청 잠금과 서버 권한 검사 변경 없음. 쿠폰의 최종 할인 금액은 서버 계산을 따른다.
- 업로드는 기존 서명 업로드를 사용한다. 학습 자료는 공개 링크로 바꾸지 않는다.
- 미션 정답은 서버 채점 및 운영자 권한 내에서만 조회한다. 미션 현황 API는 회원관리 권한 확인 후 현재 페이지의 수강권 및 선택 주차만 조회한다.
- 일반 관리자 표는 모바일 라벨 카드, 미션 매트릭스는 가로 스크롤 및 고정 회원 열을 사용한다.
- 페이지 검색/필터와 요약이 현재 서버 페이지 기준인 곳은 그 범위를 안내한다.

## 시안에서 그대로 가져오지 않은 동작

시안은 브라우저 메모리만 바꾸는 프로토타입이므로 다음은 신규 개발 또는 운영 데이터 설정 대상이며, 이번 ‘개발된 기능 이전’에서 작동하는 것처럼 표시하지 않는다.

- 가상 워크시트·샘플 성과 수치·가상 결제, 이메일/비밀번호 가입.
- 아티클 상단 ‘무료 3강’ 전용 배너 설정: 현재는 기존 미리보기 학습과 접근 가능한 영상만 연결. 별도 배너 설정 저장 기능은 없음.
- 상품별 공개 다운로드/회원 전용 자료의 새로운 권한 체계: 현재 수강권 기반 다운로드 유지.
- 제출 첨부파일·피드백만 저장·알림 발송·새 결제 수단처럼 기존 API에 없는 동작.

## 검증 기록

- TypeScript 검사 및 Next 프로덕션 빌드 통과.
- 기존 보안/결제/환불/퀴즈/권한 회귀 + 신규 화면 렌더·CSS 재생성·메뉴 범위·미션 현황 테스트 통과. 최종 개수는 CI 결과를 기준으로 한다.
- 원본 CSS 재생성과 실제 가져온 파일의 일치, 시안 JavaScript 미포함 검사.
- 로그인·결제·환불·업로드의 실제 브라우저 수행, 47개 화면의 픽셀 비교와 실기기 반응형 검수는 이 변경에서 완료한 검증으로 계산하지 않는다.
- 운영 반영은 DEV 확인 후 별도 승격 단계다.
