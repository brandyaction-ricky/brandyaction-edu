# 무료클래스 성과 대시보드

## 구현

- 무료클래스 트래킹 메뉴의 CTA·상세 이미지·맞춤 섹션·Pixel 설정 폼을 제거했다. 기존 설정과 발행 기록은 삭제하지 않았다.
- 참고 화면의 Marketing Performance, 7D/30D/90D 선택, 지표 카드 5개, 방문·클릭 추이와 Top Sources를 구현했다.
- 신규 읽기 전용 `/api/landing/performance`는 마케팅 권한을 확인하고 서버 집계만 반환한다. 방문자·세션 식별자와 원본 이벤트는 반환하지 않는다.
- 고유 방문자는 기간 내 브라우저 식별자 중복 제거, 전환율은 CTA를 클릭한 고유 방문자 / 전체 고유 방문자로 계산한다. 구매 전환율이 아니다.
- 방문별 체류 시간은 화면이 보인 시간만 측정하고, 스크롤은 방문별 최대 깊이를 사용한다. 과거 미측정 값은 NULL로 보존하고 평균에서 제외한다.
- 15초 간격 및 페이지 이탈·CTA 클릭 시 누적 측정값을 전송한다. 기존 이벤트 중복 제거와 테스트 모드·수집 중지 설정을 유지한다.
- 기존 트래킹 설정이 없는 클래스는 ‘수집 설정 없음’으로 표시한다. 이 작업은 기존 수집 중지 설정을 활성화하거나 신규 클래스의 추적 설정을 자동 생성하지 않는다.

## 적용 상태

- 로컬 기능 테스트 및 전체 회귀 테스트 109개 통과, TypeScript 검사 통과, ESLint 오류 없음(기존 이미지 경고 15개).
- DEV DB에 `20260913101517_landing_performance_dashboard.sql`의 추가 컬럼·함수를 적용했다. 기존 데이터 및 설정 변경 없음.
- 신규 함수는 SECURITY INVOKER이며 실행 권한은 service_role에만 부여했다.
- DEV 직접 SQL 검증은 현재 연결의 함수 EXECUTE 권한 거부로 중단했다. 권한 확대, 역할 전환, 우회 실행은 하지 않았다.
- UI 코드의 DEV 배포와 실제 관리자 화면 검증은 아직 완료하지 않았다. 운영 환경은 변경하지 않았다.

## 후속 검증

- 사용자가 진행 경로를 확인하면, 정상 관리자 API 경로에서 7·30·90일 집계와 수집 중지·미설정 상태를 검증한다.
- 반복 방문자·중복 클릭·구성 버전 변경·과거 미측정 값에 대한 DB 집계 검증이 필요하다.
- 기존 DEV CI 마이그레이션 실행기는 별도 체크섬 이력을 사용하므로, 해당 마이그레이션은 재실행해도 데이터를 바꾸지 않도록 작성했다.
