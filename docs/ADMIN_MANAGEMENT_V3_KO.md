# 상품·기수·사이트 설정 v3

## 반영 기능

- 관리자 상품 목록에서 복수 상품 신규 등록 및 수정
- 상품별 이미지 상세페이지 업로드, 드래그·버튼 순서 변경, 노출 순서 저장
- 상품별 커리큘럼 추가·수정 및 기존 강의 ID 유지
- 수강 진도가 있는 강의 삭제 차단
- 활성 수강권 기준으로 고객 `내 클래스`에 복수 클래스 노출
- 기수별 모집기간과 실제 운영 시작일·종료일 분리 저장
- 고객 클래스 목록·상세·내 클래스에서 기수 운영기간 노출
- 사이트 설정의 기본 정보, 메인 배너, 메뉴·페이지, 결제·환불, 약관·정책, 운영자 권한 메뉴 활성화
- 사이트명·헤더 메뉴·CTA를 고객 사이트 헤더에 반영
- 공통 푸터 사업자 정보와 정책 페이지 3종을 고객 사이트에 반영
- 본문 `p` 12pt, `span`·`small`·관리자 입력 요소의 최소 가독 크기 확대

## 데이터 반영 규칙

- 상품 상태가 `판매 중(published)`일 때 고객 클래스 목록과 상세페이지에 노출됩니다.
- `내 클래스`에는 상품 등록만으로 노출되지 않습니다. 결제 완료 또는 관리자가 발급한 `active` 수강권이 있어야 합니다.
- 이미지 순서는 `course_assets.display_order`에 저장되며 고객 상세페이지도 같은 순서로 조회합니다.
- 기수 운영기간은 `cohorts.operation_start_at`, `cohorts.operation_end_at`에 저장됩니다.
- 사이트 설정은 기존 `site_settings` 테이블을 사용하므로 별도 DB 마이그레이션이 필요하지 않습니다.
- 푸터의 통신판매업 신고번호는 값이 입력된 경우에만 노출됩니다.

## 배포 전 확인

1. 관리자 계정으로 신규 상품 1개를 임시저장합니다.
2. 상세 이미지 3장을 올리고 순서를 변경한 뒤 고객 상세페이지를 확인합니다.
3. 테스트 기수의 운영 시작일·종료일을 저장하고 상품 상세와 내 클래스에서 기간을 확인합니다.
4. 테스트 회원에게 활성 수강권을 발급해 내 클래스에 등록 상품이 표시되는지 확인합니다.
5. 사이트 설정의 각 메뉴를 저장하고 고객 헤더 노출을 확인합니다.
