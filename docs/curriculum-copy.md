# 기존 커리큘럼 불러오기

같은 상품의 모든 기수는 커리큘럼을 공유합니다. 같은 내용을 그대로 운영하면 기수만 추가합니다. 이전 기수의 내용을 바꾸면서 원본을 보존하려면 **새 클래스 상품**을 ‘작성 중’으로 저장하고 커리큘럼 탭에서 원본 상품을 선택합니다. 기수별 독립 버전 기능은 아닙니다.

원본을 검색하고 주차·학습·콘텐츠·미션·퀴즈·공통 자료 수를 확인한 뒤 ‘비공개로 불러오기’를 누릅니다. 완료 후 새로고침하여 내용을 편집합니다. 주차와 학습을 검수한 다음 필요한 항목을 공개합니다. 상품 가격·모집 일정·기수·수강 권한은 별도로 설정합니다.

- 새 ID로 주차, 학습, 미션, 퀴즈 revision과 공통 자료 항목을 만듭니다. 본문·미션 입력 양식·퀴즈 정의를 복사합니다.
- 주차·학습·미션 공개와 학습 미리보기는 모두 꺼집니다. 학습 접근 범위와 공통 자료 다운로드 범위는 원본을 유지합니다.
- 영상 URL과 파일 경로는 원본을 참조합니다. 파일을 이동하거나 삭제하지 않습니다. 내용을 수정해도 원본 커리큘럼은 바뀌지 않습니다.
- 가격·모집 일정·상세페이지·수강생·결제·학습 진도·제출·퀴즈 응시 이력은 복사하지 않습니다.
- 대상은 주차(보관 주차 포함)와 공통 자료가 전혀 없는 작성 중 클래스여야 합니다. 기존 상품은 덮어쓰지 않습니다.
- 원본 확인 후 내용이 바뀌면 다시 확인해야 합니다. 중간 오류는 전체 취소, 동일 요청 재시도는 동일 결과를 돌려줍니다.
- 원본 상한은 주차 100개, 학습 1,000개, 내용 10MB, 공통 자료 30개입니다.

## 배포

20260927031849_copy_product_curriculum.sql 한 건을 코드보다 먼저 적용합니다. 새 함수 3개만 추가하며 기존 테이블·결제 함수·권한 정책은 변경하지 않습니다. 서버 service_role만 호출할 수 있고 두 작업 함수는 활성 운영자의 products 권한도 확인합니다. 복사 감사 기록은 curriculum.copied로 남습니다.

DEV에는 저장소에 없는 curriculum_missions.form_schema 확장이 있어, 존재할 때만 해당 정의도 복사합니다. 이 열을 추가하거나 변경하는 migration은 포함하지 않습니다. 각 환경의 실제 스키마와 적용 이력을 먼저 대조하고, 다른 미적용 migration 전체를 일괄 실행하지 않습니다.
