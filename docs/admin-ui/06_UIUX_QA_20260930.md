## 화면별 보완

- 주문·결제: 필터를 데스크톱에서는 한 줄 작업 흐름으로 정리하고 중간 폭에서는 검색 영역부터 자연스럽게 줄바꿈한다.
- 회원·상품·기수·주차·쿠폰·배너·아티클 등 공통 Admin 목록: 필터, 표, 페이지네이션의 공통 레이아웃 규칙을 함께 적용한다.
- 상품·콘텐츠 카탈로그: 우측 관리 액션이 가로 스크롤 중에도 유지되도록 한다.
- 전체 Admin: 페이지 이동 시 활성 메뉴가 사이드바 가시 영역에 들어오되 본문 스크롤은 이동시키지 않는다.
