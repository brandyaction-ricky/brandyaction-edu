# EDU TIPS v2 삭제 요청 보관 — 1단계

상태: 로컬 구현. 실제 DB 적용·공유 DEV 반영·운영 활성화는 별도 승인 대상이다.
기준: 2026-10-09 전달한 EDU v2 API 구현 후보 2.0.0-rc.2 변경 후보. 2026-10-10 대표 방침에 따라 5일/30일/30일로 통일 준비하되 TIPS 가능 회신 전 확정·실제 DB 적용 금지.
OS 점검 중 먼저 개발하라는 대표 지시에 따라 작업했으며 OS 개발 로그 등록은 복구 후 진행한다.

## 구현 범위

- EDU 전용 가명 고객 ID와 동의 세대를 private schema에 보관한다. 원래 회원 UUID는 내부 연결에만 쓰고 작업 반환값에는 포함하지 않는다.
- `edu_tips_register_subject`는 현재 고지, 분석·해외 처리 두 동의, 최신 동의 revision, 활성 외부 회원 여부를 확인한다. 같은 식별자의 재시도는 허용하며 다른 식별자 덮어쓰기는 거절한다.
- 동의 철회/동의 고지 교체, 계정 탈퇴·삭제, 내부 회원 전환 시 식별자를 중지하고 삭제 요청을 **같은 트랜잭션**에서 남긴다. 처리 실패 시 변경 전체가 되돌아가므로 삭제 요청만 빠지는 상태를 만들지 않는다.
- 삭제 요청 UUID는 재시도 동안 유지된다. 여러 작업자의 중복 선점을 `FOR UPDATE SKIP LOCKED`로 막고 60초 lease와 매 선점마다 바뀌는 lease token으로 이전 작업자의 뒤늦은 결과를 거절한다. 재시도 간격은 30초부터 최대 1시간이다.
- 변경 후보의 분석 사본 삭제 기한은 요청 시각+5일, 모델 처리와 백업 등 잔존 처리 기한은 각각 요청 시각+30일이다. 동일 statement timestamp와 UTC 경과시간(120/720/720시간)으로 계산하며 재시도는 기한을 연장하지 않는다. 기존 목표24시간/상한72시간·모델7일은 이 후보의 기준이 아니다. 미적용 draft SQL만 수정했으며 기존 기록을 일괄 변경하지 않는다. 이 컬럼을 추가했다고 원격 삭제가 실행되는 것은 아니다.
- `delivered_at`은 요청 전달에 성공했다는 뜻이다. `completed_at`은 실제 삭제 완료 회신으로만 향후 기록한다. 현재 단계에서 서버 역할은 완료 열을 수정할 수 없으며, 완료되지 않은 요청이 있으면 새 식별자를 등록할 수 없다.
- 공개·로그인 역할은 private table과 RPC에 접근할 수 없다. 서버 역할에도 기존 고지 수정 권한을 추가하지 않는다. 현재 고지 잠금은 검색 경로를 고정한 작은 definer 함수만 수행한다.

## 이번 변경에 없는 것

- HTTP API, 외부 전송 작업자, TIPS 호출, 배포, DB 실행, 예약 작업, 고객 동의/식별자 초기 등록, 고객별 분석 활성화.
- 삭제 단계별 receipt 저장, 완료 검증, 연속 ACK, 실제 모델·백업 삭제 검증. 따라서 전달 성공 후 재동의로 분석을 재개하는 경로도 아직 열리지 않는다.
- 동의 확인만으로 원격 실행 중인 작업이 즉시 멈춘다는 보장. TIPS의 중지 수신 경로·권한·처리 계약과 공동 검수가 추가로 필요하다.
- 현재 학습 원장으로 과거 매일의 반복 이용을 복원하는 기능. 중간 날짜 원장이 없으므로 별도의 수집 보완이 필요하다.

## 적용 전 검수

기존 personalization consent SQL이 먼저 적용돼 있어야 한다. 현재 migration에는 초기 데이터와 기능 플래그 변경이 없다.

로컬 PGlite에서 실제 SQL을 적용해 명시적 동의, 회원 간 분리, 철회 트랜잭션 rollback, 중복 요청, 탈퇴 cascade, 고지 변경, lease 재선점/이전 token 거절, 권한, 완료 전 재등록 차단을 시험한다.

PGlite는 단일 연결 검수다. 실제 DEV의 동시 연결로 다음 경쟁 조건을 확인한 뒤 활성화해야 한다.

1. 동의 철회와 식별자 등록이 동시에 실행될 때 활성 식별자가 남지 않는지.
2. 고지 비활성화와 등록이 겹칠 때 구 고지 식별자가 남지 않는지.
3. 두 작업자가 같은 요청을 동시에 가져가지 않는지와 lease 만료 후 이전 작업자 결과가 무시되는지.
4. 기존 회원 탈퇴 경로 전체와 원격 TIPS 삭제 회신·연속 ACK를 연결한 종단 검수.

실제 적용 후 되돌릴 때는 분석/전송 연결을 중지하고 식별자·요청·처리 기록을 보존한다. outbox를 삭제하는 역방향 SQL은 제공하지 않는다.
