## 기능과 보안 계약

- 수강권 ID는 로그인한 회원의 활성·유효기간 내 목록에서만 선택한다. URL에 다른 회원 ID를 넣어도 사용하지 않는다.
- 쿠폰·후기 특권 조회 전에 인증 및 활성 프로필을 확인하고 `user_id`로 범위를 제한한다.
- 브라우저에 비공개 Storage 경로를 전달하지 않는다. 실제 다운로드 API가 수강권·공개 상태·파일 경로를 검사한 후 짧은 유효기간 URL을 발급한다.
- 달성도는 공개된 필수 미션의 승인 비율이며 영상 진도와 분리한다. 퀴즈 통과만으로 완료 처리하지 않는다.
- 쿠폰·결제 금액·수강권 발급의 서버 검증 및 기존 idempotency 처리는 변경하지 않는다.
- 결제 SDK는 주문 검증 후 실제 유료 결제를 시작할 때만 불러온다. 무료 신청은 SDK를 로드하지 않는다.
- 기존 외부 이미지 URL도 표시되도록 하되 서버 이미지 프록시는 명시된 공개 버킷만 사용한다.
- 후기 저장 중 네트워크 오류가 발생하면 입력 내용을 보존하고 버튼을 다시 활성화한다.
