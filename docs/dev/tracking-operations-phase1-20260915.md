## 계산식

- 방문→CTA = 클릭 세션 / 전체 세션 × 100. 클릭 횟수는 분자에 사용하지 않음.
- 카톡방 = day ≤ 조회 종료일인 기록 중 kakao_members가 null이 아닌 가장 최신 값.
- 결제 = 조회 시작일 ≤ day ≤ 종료일의 신규+기존 결제 합. 모두 미입력이면 null, 명시적 0은 0.
- CTA→카톡방 및 카톡방→결제는 다음 값 / 이전 값 × 100. 분모 0 또는 값 없음은 계산 불가.
- 카톡방은 인원 스냅샷이므로 동일 개인 전환율이 아니며 100%를 넘을 수 있음을 설명.
- 필터 적용 시 실측 수치는 캠페인 전체 값임을 표시하고 CTA 이후 실측 전환율은 숨김.
- 기존 RPC의 방문·전환·매출·ROAS·CSV 계산 변경 없음. 캠페인 누적 성과는 상세 지표와 실측 요약에 유지.
