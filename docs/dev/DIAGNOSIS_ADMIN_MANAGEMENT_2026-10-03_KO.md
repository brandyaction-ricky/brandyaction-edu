# N6 진단 관리 실행·검증 기록

- 직접 진단: `/admin/diagnosis`, 메뉴 `N6 진단 받기`. 관리자 테스트·재설문 동작 유지.
- 수강생 관리: `/admin/diagnosis/manage`, 관리자만 접근. API도 현재 활성 관리자 권한을 재검증한다.
- 전체 공개/닫기는 개별 설정을 같은 값으로 맞춘다. 새 수강생은 전체 기본값을 따른다. 개별 공개도 가능하다. 기존 시작·제출 답변은 닫기로 삭제되거나 중단되지 않는다.
- 현재 권한을 가진 대상 상품 수강생만 공개 가능. 회원별 1회 제한, 환불·권한 회수 시 차단 유지. 학생에게는 공개 후 학습 메뉴와 시작 카드가 나타난다.
- 페이지당 최대 100명, 이름 검색·이전/다음, 보이는 탭에서 30초마다 상태 확인. 작은 화면은 카드 표시.
- 보고서 최신 상태·시각·안전한 오류 코드와 최근 기록을 표시한다. 서버 조회 실패 시 마지막 기록임을 표시하며 재발급을 잠근다.
- 재발급은 MYIN에 저장된 같은 답변·보고서 작업을 재개한다. 발급 완료/실행 중/미확정 비용은 재발급 금지. 현재 권한·숫자 검증·예산·공유 동시 처리 한도 유지. 요청 UUID·버전 비교·양쪽 기록으로 중복 접수 방지.
- MYIN 연결 PR의 `/api/integrations/edu/diagnosis/manage`와 DB RPC가 먼저 필요하다. 새 HMAC 도메인으로 관리자 브라우저 요청과 기존 문진/보고서 서명을 분리한다.

## 검증과 배포 경계

로컬 가상 DB/API와 모델 스텁을 사용한다. 실제 유료 AI·학생 공개·실제 재발급은 실행하지 않는다. EDU 전체 단위 1,181개, 관리 UI 12개(PC/태블릿/모바일 및 320px), 기존 진단 UI 85개 통과. TS/lint/Next 빌드 통과. MYIN 최신 DEV를 보존한 연결 브랜치의 EDU 회귀 104개 및 Nuxt 빌드 통과. 발급된 HTML·체크포인트·비용 원장이 재발급 요청으로 바뀌지 않는 검사 포함.

새 migration: EDU `20261003070134`, MYIN `20261003070713`. 운영 적용은 대상 커밋·두 DB 경계 확인 후 별도 승인한다. 기본 공개값 false이며 migration/코드 배포 자체는 수강생을 열지 않는다. Preview에서 실제 수강생의 설정을 바꾸지 않는다. 운영 환경변수·실제 상품 바인딩 변경 없음.

공유 파일 변경은 EDU admin-shell 메뉴명/관리 메뉴와 member-views 진단 링크만, MYIN 인증 middleware의 정확한 관리 API 경로 한 줄만이다. 공통 엔진·문항·채점·프롬프트·고객 보고서 디자인 변경 없음.
