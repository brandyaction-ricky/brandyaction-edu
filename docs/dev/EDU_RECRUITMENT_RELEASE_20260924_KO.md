이 후보는 `main`의 `2a07717`에서 출발해 `develop`의 `c001e44`에 있는 에듀 모집·전환·CRM 코드를 가져왔다. Toss 웹훅·가상계좌 변경은 포함하지 않는다. 이 문서는 배포 승인이나 실제 배포 기록이 아니다.

## 포함 범위

- 무료 웨비나 신청, 광고·오가닉 대기방 링크, 모집 운영, 방송·후속 안내, 전환 관리 및 Jev 검수 화면
- 모집 안내의 발송 대상 검토와 안전한 예약, 기존 자동 메시지 대기열의 독립 정지, DEV 전용 지정번호 SMS 연결 시험
- 상품 상세 CTA와 관리자 모집 동선, 마케팅 대시보드 귀속·필터 개선
- `20260916*`~`20260917*` 마케팅 집계 migration 5개와 `20260920*`~`20260923*` 에듀 모집·전환 migration 20개

## 명시적으로 제외한 Commerce 범위

`app/api/payments/toss/webhook/route.ts`, `app/api/platform/payment/route.ts`, `app/ui/final/checkout.tsx`, `app/ui/order-result.tsx`, Toss 웹훅·가상계좌 테스트와 문서는 이 후보에 없다. 결제는 기존 `main`의 카드 결제 구현을 유지한다. 위 파일을 되돌리려고 운영 `main`에 역방향 변경을 넣는 방식도 사용하지 않는다.

## 확인된 검수와 한계

- 후보 코드: 단위·계약 테스트 318/318, 브라우저 테스트 153/153, TypeScript, ESLint(오류 0, 이미지 경고 15), Next.js 빌드 통과.
- DEV: 무료 웨비나 신청 화면과 광고·오가닉 경로 확인. 문샷 챌린지 4기 상품을 대표 승인하에 잠시 공개하고 `[DEV 검수안]` 6주·6레슨으로 상품→결제 화면의 165만 원 표시를 확인했다. 실제 결제·주문 생성은 하지 않았다. 상품은 `작성 중`, 시험 커리큘럼은 전부 비공개로 복구했다.

## 운영 반영 전 결정 및 순서

1. GitHub의 `main` PR 검사가 현재 `develop` 출발 PR만 허용한다. Commerce와 분리된 이 후보를 검토할 수 있도록 저장소 관리자와 독립 승격 규칙을 확정한다. 검사 우회용 CI 수정은 이 후보에 포함하지 않는다.
2. 운영 Supabase에 위 25개 migration의 적용 여부·순서·기존 스키마와의 호환성을 사전 점검하고, 승인된 migration만 코드 배포보다 먼저 적용한다.
3. 운영 Vercel의 필수 서비스 연결을 확인한다. Jev 외부 판정은 DEV 전용이고, `CRM_AUTOMATIONS_ENABLED=false`를 유지한다. 고객 메시지 발송은 발신번호·수신거부·카카오 승인 템플릿·대상 동의와 기존 대기열 처리 계획을 확인할 때까지 정지한다.
4. 실제 4기 공개 커리큘럼·최종 상세페이지와 유튜브 라이브 주소를 등록한다. 시험 커리큘럼은 운영에 복사하지 않는다. 상품 가격 165만 원, 최초 마감 10월 1일 23:59, 누구나 같은 가격인 조건을 공개 화면과 결제 화면에서 확인한다.
5. 정확한 코드 커밋·DB migration·운영 환경 변수 변경 묶음을 대표가 수용한 뒤 `main` 병합·Vercel 배포·관리자/고객 기본 동선 확인을 수행한다. Commerce 승격은 별도 요청으로 유지한다.
