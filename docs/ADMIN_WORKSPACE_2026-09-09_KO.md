# 관리자 운영 화면 및 무료 클래스 퍼널 반영

## 적용 기준

2026-09-09 업로드된 회원·상품·참가자·미션 관리 시안을 기준으로 실제 데이터와 기능을 연결했다. 기본 구조는 사이드바 → 페이지 제목 → 검색·필터 → 목록 → 상세 패널이다. 시안의 예시 회원·상품·숫자는 DB에 입력하지 않았다.

- 배경 `#f6f7f9`, 흰 패널, 구분선 `#e2e4e8`, 본문 `#202124`, 브랜드 강조 `#a10d12`.
- 페이지 제목 28px, 섹션 제목 18px, 하위 제목 15px, 표·입력 13–14px, 보조 정보 12px.
- 기본 실행 버튼은 검정, 미션 등록과 전환 CTA는 레드, 상태 배지는 색상과 텍스트를 함께 표시.
- 회원·상품·미션·그룹·참가자는 페이지 이동 없이 상세 패널에서 확인하거나 편집한다. 모달의 초점 제한과 닫기, 저장 중 중복 실행 차단을 적용한다.

## 미션·달성도 규칙

- 미션은 기존 커리큘럼 콘텐츠에 연결되며 클래스의 모든 기수에 공통 적용된다.
- 주차 내부 미션 정렬은 미션이 있는 콘텐츠의 위치끼리만 이동한다. 일반 강의·자료의 위치와 모든 기존 ID·진도·제출 이력을 유지한다.
- 등록·편집은 즉시 저장하며 주차·콘텐츠·미션 공개 상태를 모두 확인한다. 별도 주차 잠금·예약 공개는 이번 변경에 포함하지 않는다.
- 기존 퀴즈 통과 → 관리자 승인 게이트를 유지한다. 퀴즈를 사용하지 않는 미션도 관리자 승인이 완료 기준이다.
- 참가자 달성도 = 공개된 필수 미션 중 승인된 비율. 반복 제출 횟수는 중복 집계하지 않는다.
- 레벨은 시작/실행/성장/성과/완주이며 0/25/50/75/100% 기준이다. 필수 미션이 없으면 달성도·레벨을 미등록으로 표시한다.
- 콘텐츠 진도는 미션 달성도와 별도다. ‘활동 주의’는 마지막 학습·제출 기록 또는 등록 후 3일 기준이며 로그인 이력 지표가 아니다.
- 미션 편집 스냅샷과 저장 시 리비전을 비교한다. 다른 운영자의 변경이 있으면 저장을 거절하고 다시 불러오도록 안내한다.

## 무료 클래스 전환 화면

- 무료 클래스만 탐색 메뉴 없는 간결한 브랜드 헤더와 신청 CTA를 적용한다. 유료 상세 화면은 기존 동작을 유지한다.
- 데스크톱은 우측 고정 신청 카드, 모바일은 하단 고정 신청 CTA를 사용한다.
- 소개·콘텐츠·무료자료·혜택·후기·FAQ는 같은 상세페이지 안에서 이동한다.
- 실제 등록된 자료만 ‘무료 자료’에 표시한다. 원본 파일 주소는 공개 HTML에 포함하지 않는다.
- 회원 무료 자료는 로그인 후 제공한다. 수강생 자료는 무료 클래스의 유효 수강권을 확인한 후 제공한다. 유료 수강생 자료는 이 경로로 접근할 수 없다.
- 다운로드 클릭 → 서버 권한·공개 상태 확인 → 이용 내역 저장 → 5분짜리 다운로드 주소 발급. 로그인 후 복귀 경로와 UTM을 보존한다.
- 자료 다운로드는 별도 자료 랜딩으로 이동하지 않는다. 약관·개인정보·사업자 정보는 공통 푸터에 유지한다.
- 무료자료를 제공하려면 상품 콘텐츠에 실제 파일을 업로드하고 해당 섹션·콘텐츠를 공개해야 한다. 파일을 임의로 생성하거나 등록하지 않았다.

## 검증 및 성능

- Node 테스트 43개: 미션 정렬·필수 승인·레벨·퀴즈 재응시·CSV 수식 방어·관리자 권한·무료자료 권한 및 만료 조건.
- DEV DB 트랜잭션 테스트: 실제 미션 등록·제출·승인·정렬·리비전 충돌·달성도 집계·그룹 중복 방지·RLS 검증. QA 데이터 전부 롤백.
- ESLint·TypeScript·Next.js 프로덕션 빌드 통과.
- 미션 초기 목록과 참가자 현황은 서버에서 DB 함수로 집계해 내려준다. 참가자는 서버에서 50명씩 조회하고 검색 요청을 300ms 지연·취소한다.
- 미션 편집기는 열 때만 로드한다. 회원 태그는 인덱스 맵으로 조회하며 목록 DOM은 50명으로 제한한다. 기존 회원 전체 조회 API 자체는 향후 대규모 데이터에 맞춘 서버 페이지네이션 전환 대상이다.
- 관리자 경로에서 불필요한 공통 푸터 설정 조회를 제거했다. 무료 클래스 썸네일은 Next 이미지 최적화를 사용한다.
- DEV의 참가자 집계 쿼리 실행 시간은 소량 데이터 기준 약 9.3ms였다. 네트워크·브라우저 렌더링 시간이나 대규모 성능 보장을 의미하지 않는다.
- 새 DB 객체의 보안 경고 없음. 그룹 생성자 FK 인덱스 권고는 별도 추가 마이그레이션으로 반영했다. 신규 인덱스의 unused 표시는 실제 사용 전 상태다.
- 브라우저 CDP 연결이 시간 초과되어 실제 클릭·모바일 시각 검증은 미완료다. 현재 이를 통과했다고 간주하지 않는다.
