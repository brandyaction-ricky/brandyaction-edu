# 관리자 UIUX 정합성 점검표

기준: 2026-09-12에 업로드한 `brandy-edu-brand-final 2(1).zip`의 관리자 22개 화면. 아래 차이점은 이번 수정 시작 시점의 `3d7c660` 소스 점검 결과다. 현재 작업에서 수정되는 항목도 있으므로, 이 문서의 차이점만으로 최신 구현 상태를 판단하지 않는다. **브라우저에서 원본과 비교한 시각 검수 통과 기록은 아직 없다.**

원본: `design-reference/source/admin/src/app.js`, `operations.js`, `interface.css`, `experience.css`. 원본의 예시 회원·통계·시연 안내를 운영 데이터로 복제하지 않는다. 로그인·업로드·저장·권한 검사는 실제 기능을 연결해 검수한다.

## 확인한 CSS 원인과 수정 위치

`app/ui/final/integration.css`에 관리자 범위의 보정 규칙을 추가한다. 생성물 `admin.css`를 직접 수정하지 않는다.

- 검색: 기본 입력 규칙 `(0,5,1)`이 검색 패딩 `(0,4,1)`보다 강해 아이콘과 글자가 겹침. 검색 규칙에서 동일한 타입 제외 조건을 적용해 우선순위를 확보한다.
- 체크박스: `.toolbar input`의 `min-height:48px`가 체크박스에도 적용됨. 텍스트 입력으로 한정하고 checkbox/radio는 20px, `min-height:0`으로 고정한다.
- 필드: `:where(...) .field` 보정이 `.edu-admin .field`보다 약함. 관리자 필드는 명시적인 세로 배치, 그리드는 `align-items:start`, 인접 필드는 하나의 gap으로 배치한다.
- 제목 버튼: 미션의 `.title-btn`은 배경/테두리 초기화가 없었음. 관리자 범위 공유 버튼 규칙을 적용한다.
- 태그/후기/링크: `.tag-list`, `.table-excerpt`, `.text-link`에 대응 규칙이 없었음. 줄바꿈·간격·본문 폭을 정의한다.
- 저장 바: 실제 `.dirty-note`에 원본 `.meta`의 자동 여백 규칙이 적용되지 않았음. 오른쪽 동작 정렬과 모바일 줄바꿈을 추가한다.
- 보관/일괄 도구: 항상 펼쳐진 일반 toolbar 대신 별도 접힘 도구로 이동하며, 펼친 상태의 정렬도 확인한다.

## 검수 기록 기준

- [ ] 운영 배포 커밋과 검수할 로컬 커밋이 일치하는지 확인한다.
- [ ] 원본과 실제 화면을 같은 viewport(1440px, 1024px, 390px)에서 비교한다.
- [ ] 검색 input의 계산된 왼쪽 padding이 48px이며 아이콘이 수직 중앙에 있는지 확인한다.
- [ ] toolbar/필드 checkbox의 계산된 크기가 20×20px이고 텍스트와 같은 행인지 확인한다.
- [ ] 표의 긴 제목·메일·파일명·태그가 전체 페이지를 가로로 밀지 않는지 확인한다.
- [ ] 상품 5개 탭, 신규/기존 상품, 파일 선택·업로드·저장·재조회·고객 화면 노출을 확인한다.
- [ ] 학습 본문/미리보기/퀴즈 저장, 미션 상품·주차 필터와 편집 결과를 확인한다.
- [ ] 회원 검색·클래스 필터·상세 drawer·계정 저장, 태그 탭과 편집을 확인한다.
- [ ] 모바일 메뉴·접힌 도구·필수값 오류·빈 목록·로딩·저장 중 상태를 확인한다.
- [ ] 기존 테스트, 타입/빌드 검증 결과와 브라우저 검수 결과를 별도로 기록한다. CSS 파일 일치나 클래스 문자열 테스트만으로 시각 검수 통과를 선언하지 않는다.

최종 확인 시 위 항목에 실행한 환경·커밋·날짜와 실패한 항목을 기록한다. 연결 또는 도구 제약으로 보지 못한 화면은 미검수로 남긴다.

## 이번 수정에 포함된 내용

- 상품 5개 탭을 원본의 2열 편집/우측 미리보기 구조로 변경했다. 실제 자료 업로드·모집 일정·HTML 상세·검색 정보 저장을 연결했다. 저장 이력이 없는 데이터는 현재 저장 정보로 표시한다.
- 학습 편집을 기본 정보 → 콘텐츠/학습자 미리보기 → 퀴즈 카드로 변경했다. 본문·영상·자료·링크를 실제 저장 유형과 맞추고, 업로드 중/실패 시 저장을 막는다.
- 상품·학습·미션·회원·태그 목록, 회원 상세 drawer, 기수 범위 요약을 수정했다. 부가 일괄 도구는 접힘 영역으로 이동했다.
- 쿠폰 실데이터 지표, 후기 작성자/상품 셀, 배너 160×82 미리보기와 운영 안내를 추가했다. 주문은 기간 조회 → 지표 → 필터/표 패널로 정돈하고 KST 종료일을 포함하도록 수정했다.
- 검색 설정은 검색·공유/소유 확인/측정·추가 코드 3개 탭과 실제 미리보기·관리 링크로 구분했다.
- 검색 아이콘, 체크박스, 탭 버튼, 입력 간격, 업로드, 저장 바, 긴 텍스트, 모바일의 공통 CSS를 보정했다.

현재 데이터 구조에 없는 상시 챌린지, 미션의 독립 순서 이동, 자료별 개별 다운로드 정책, 상세 버전 이력, 학습 Tip/퀴즈 해설은 기능이 있는 것처럼 구현하지 않았다. 본 문서는 UI 이식 범위와 실제 기능 범위를 구분한다.

검증: 90개 회귀 테스트, TypeScript, ESLint 오류 0, Next.js 운영 빌드 성공을 확인했다. 브라우저 CDP 연결의 탭 갱신이 시간 초과로 실패하여 원본/실제 화면의 1440·1024·390px 시각 대조 및 인증된 저장·재조회 동작은 미검수다. 이를 완료로 표시하지 않는다.
