# 문샷 캠퍼스 · EDU 기능 연결

이 브랜치는 처음 전달한 윤익님 인계 ZIP을 기준으로 EDU 연결 기능을 독립 개발합니다. 원본 ZIP은 변경하지 않았습니다.

- 원본 SHA256: `12a533d4459e34bc55cb5abbc804ca49f7997793b28711c4cfffaec470044171`
- `public/campus/world/`는 EDU 연결을 검수하는 별도 복사본입니다. 원본 인계 폴더와 윤익님 반환 합본을 자동 덮어쓰지 않습니다.
- 사용자 기능·코드·검수 대응표와 환경별 검수 증빙은 내부 로컬 기록으로 보존하며 공개 저장소에 포함하지 않습니다. **로컬 구현과 DEV/운영 반영은 별도 상태**입니다.
- 실제 배포 상태와 개발 이력의 정본은 BRANDYACTION OS 개발 기록입니다. 이 README는 실행 가능한 코드 계약만 설명합니다.

## 화면과 기능

| 경로 | 용도 |
|---|---|
| `/campus` | 내 수업·과제 상태, 다음 행동, 15분 실행 |
| `/campus/workspace` | 공간·결과물/피드백·사업 실행·지원·AI/멘토·오피스·실행 수첩 |
| `/campus/archive` | 정상 수료/만료 후 허용되는 본인 자료만 복사·편집하는 개인 보관함 |
| `/campus/review#…` | 명시적으로 발급·공유한 유효기간 있는 고객 리뷰 링크 |
| `/admin/campus` | 기수별 학습·제출 현황과 지연 확인 |
| `/admin/campus/operations` | 지원/예약/확인 계획·성과 사례 검토·공간 공지/제어·요청 관측 |

학습 완료·과제 승인·동료가 확인한 피드백·집중 타이머·자기기록 사업수치는 서로 다른 근거로 표시합니다. 타이머나 방문 횟수가 과제 승인·로켓 발사 자격으로 자동 환산되지 않습니다.

공개 전환은 항목별 명시 동작입니다. 개인 메모·사업 자료·AI 대화·오피스는 기본 비공개이며, 첨부 공유는 게시글 공유와 별도로 선택합니다. 활동의 이익과 매출의 인과관계를 단정하지 않습니다.

## 격리와 환경

`EDU_CAMPUS_ENABLED` 및 필요한 세부 스위치가 `true`일 때만 API를 엽니다. 스위치 기본값은 OFF입니다. 세부 값은 `.env.example`에 있으며 실제 비밀값을 저장하지 않습니다.

- Supabase 인증/RLS가 본인·기수·수강권·공개/보관 상태를 검증합니다. 운영자 권한도 각 API에서 재확인합니다.
- 실시간 이동은 브라우저에서 처리하고 DB에 프레임을 기록하지 않습니다. 동료 연결·좌석·대화는 실제 서비스 경로를 사용합니다.
- HTTP 관측은 응답 이후 서비스 전용 RPC가 5분 단위 수량·지연만 합산합니다. 메시지·사용자 ID·이동 경로를 보관하지 않습니다. 관측 누락과 공급자 WebSocket 전체 사용량은 구분합니다.
- AI는 직원 DEV에서 검수한 기존 모듈과 키를 재사용합니다. 과거 AI SQL은 `tests/fixtures/ai-reference-migrations/`에만 보존하며 현재 DB에 다시 적용하지 않습니다.
- 봇 연결은 명시적으로 등록된 서명 검증 어댑터만 수신합니다. 연결 정보가 없으면 `awaiting_connection`이며 가짜 작업 완료를 만들지 않습니다.

## 윤익님 합본 인수 계약

1. 원본 ZIP 해시와 반환 합본의 변경 파일을 비교합니다. 반환 파일을 저장소 루트에 통째로 덮어쓰지 않습니다.
2. EDU 데이터는 `/campus/edu-bridge.mjs`와 호스트 패널을 통해 읽습니다. 각 수업 이동 직전에 이용 권한을 새로 확인합니다.
3. 3D 프레임은 같은 출처·정확한 source window·세션 토큰이 일치하는 메시지만 받습니다. HTML/외부 iframe을 사용자 콘텐츠로 삽입하지 않습니다.
4. 카메라·캐릭터·렌더러는 교체 가능한 프레젠테이션 계층입니다. 과제/피드백/리뷰/AI/권한 저장은 EDU API에 남깁니다.
5. 외부 봇은 `features/campus/office/ADAPTER.md`의 서명·중복·검토 계약으로 붙이고 실제 외부 작업 전 수신·권한 검수를 합니다.

## DB 변경과 검수

DEV 전용 계획은 `dev-migrations/manifest.json`의 고정 파일·해시만 적용합니다. 충돌/의존성 검사·공유 객체 권한 백업·적용 후 메타 검증·롤백형 가상 데이터 검수 파일이 함께 있습니다. 준비 파일 존재는 실제 적용 성공을 뜻하지 않습니다.

데이터가 생긴 뒤에는 신규 테이블/버킷을 자동 삭제하지 않습니다. 기능 스위치를 끄고 증빙을 보존한 채 별도 복구를 검토합니다. 운영 사이트와 공유 DEV 기준 배포는 이 로컬 명령으로 변경되지 않습니다.

```sh
npm test
npm run lint
npx tsc --noEmit
npm run build
npx playwright test
npx playwright test --config=playwright.campus.config.ts
```

브라우저 fixture는 가상 데이터 전용이며 실제 API 호출/회원 저장을 검수했다고 간주하지 않습니다. 긴 공간 검수는 `tests/campus-space-soak.test.mjs`의 별도 옵트인 실행입니다. 로컬 headless FPS는 실제 기기의 GPU 성능 보장이 아닙니다.

## 내부 검수 기록의 보관 범위

`coverage-audit-business.json`, `coverage-audit-final.json`, `schema-dependency-audit.json`은 요구사항별 내부 판단과 대상 환경 메타데이터를 보관하는 로컬 전용 파일입니다. `dev-migrations/03-seed-metadata-baseline.json`과 `dev-migrations/04-trigger-risk.private.md`도 운영자가 검토한 해당 환경의 지문·진단 원문으로, 공개 저장소에서 제외합니다. 이 파일들은 런타임이나 로컬 테스트의 입력이 아닙니다.

공개된 `ai-reuse-manifest.json`은 원본 커밋·파일 해시와 현재 적용본 해시를 유지합니다. 개인 체크아웃 경로나 내부 환경 원문은 포함하지 않습니다. DEV 실행 전에는 담당자가 별도로 보관한 최신 검토 증빙과 지문을 확인해야 하며, 파일이 없다고 안전 게이트를 생략하거나 새 지문을 자동 승인해서는 안 됩니다.
