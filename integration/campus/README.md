원본 ZIP SHA256: `12a533d4459e34bc55cb5abbc804ca49f7997793b28711c4cfffaec470044171`.
파일별 기준은 `original-prototype.sha256`에 보존했다. 합본 수령 시 원본 대비 변경을 확인하고 기존 작업을 덮어쓰지 않는다.

## 현재 구현

- `GET /api/campus`: 기존 활성 회원 인증과 사용자 세션/RLS로 본인의 이용 가능한 수강권을 조회한다. `enrollmentId`를 선택하면 그 과정의 공개 수업, 공개 과제, 본인 최신 제출 상태·수업 완료 여부만 전달한다.
- `features/campus`: 공개/권한 필터, 작은 응답 모델, 서버 읽기 처리. 과제 본문·피드백 원문·이메일·결제·토큰·AI 답변은 읽거나 전달하지 않는다.
- `public/campus/edu-bridge.mjs`: 프레임워크 독립 연결 코드. 기수 선택/갱신, 기존 수업·과제·내 질문 화면 이동. 이동 전 수강권과 공개 상태를 새로 확인한다. 수업 ID 기준으로 연결하고 버전을 전달한다.
- `EDU_CAMPUS_ENABLED=true`인 환경에서만 서버 경로가 열린다. 기본 OFF이며 실제 환경변수는 변경하지 않았다. 1차 연결은 읽기 전용이다. 이후 추가한 개인 실행 기록의 별도 SQL·쓰기 경로는 아래에 구분했으며 실제 DB 적용·회원 메뉴 추가·캠퍼스 공개는 하지 않았다.
- 원래 프로토타입의 데모 과제/집중 타이머/XP/피드백은 서버 기능이 아니다. 이번 API는 그 데모를 진짜 기록이라고 저장하지 않는다. 동료 피드백과 로켓 발사 판정은 미구현이므로 `launchEligibility: null`을 반환한다.

## 합본 화면과 연결할 지점

동일 EDU 출처의 화면에서만 아래 모듈을 가져온다. 다른 출처 iframe 인증/postMessage는 아직 지원하지 않는다. 반환된 문구는 textContent나 React 텍스트로 렌더링하고 innerHTML에 넣지 않는다.

```js
import { createEduBridge } from '/campus/edu-bridge.mjs';
const edu = createEduBridge({
  onState(state) {
    // loading/error/closed: 이전 회원·수업 표시 제거
    // ready: state.snapshot.scopes를 기수 선택에, lessons를 미션 지도에 연결
  },
});
const context = await edu.load();
// 사용자가 선택한 enrollmentId로 await edu.load(enrollmentId)
// 수업: edu.openLesson(enrollmentId, lessonId)
// 과제 입력/피드백: edu.openMission(enrollmentId, lessonId, missionId)
// 내 질문: edu.openQuestions()
// 로그아웃/화면 이탈/컴포넌트 해제: edu.dispose()
```

이 모듈은 루프나 위치 동기화를 만들지 않는다. 캐릭터 이동·카메라·렌더러는 윤익님 코드에 남는다. 공개 자료는 전체 수강권 중 선택한 과정만 읽는다. 목록이 한도를 넘거나 DB 조회에 실패하면 부분 목록을 완성된 지도처럼 표시하지 않고 오류를 반환한다.

### 데이터 해석과 성능

사람 수는 중복 수강권을 합쳐 집계하지만, 미처리 제출물은 수강권별 최신 제출을 보존한다. 기존 승인된 다른 수강권 때문에 처리할 제출물이 사라지지 않는다. 상태가 겹칠 수 있어 열별 인원을 합산하지 않는다. 관리자 제출 이력은 페이지 단위로 읽고 최대20,000건을 넘거나 일부만 읽으면 오류로 처리한다. 화면 지원 목록은 최대100건이며 필터는 표시된 목록에만 적용된다.

현재 지표는 학습·실행 과정이다. 매출/고객 확보/시간 절감/장기 실행 지속은 수집하지 않아 표시하지 않는다. 교육 세일즈에 쓸 때는 ‘개인 실행 기록과 운영 지원을 확인할 수 있는 기능’으로 설명하고, 교육 효과·매출 증가의 검증 수치처럼 사용하지 않는다. 공개 사례 사용은 별도 동의·검증이 필요하다.

정기 폴링·애니메이션별 API·유료 AI 호출·자동 발송을 추가하지 않았다. 메뉴/3D 화면에 자동 연결하지 않았고 기본 OFF를 유지한다. 윤익님 합본은 이 화면을 열거나 기존 어댑터로 같은 데이터를 받아 표현하면 된다.

## 15분 실행·복귀 기록 추가 (2026-11-02)

수강생 성장보드에 `수업 선택 → 작은 일 하나 정하기 → 15분 실행 → 잠깐 멈춤/복귀 → 오늘 한 일·다음 할 일 남기기`를 연결했다. 다음에 열면 진행 중인 실행 또는 최근 마무리 기록을 읽는다. 최근의 다음 할 일을 입력란으로 가져와 새 실행을 시작할 수 있다.

### 저장과 표시 범위

- `features/campus/focus-domain.ts`: 시간·상태 전이, 내용 길이, 버전 충돌 검증. 목표 시간은 15분이며 일시정지 시간은 제외한다. 시간 종료만으로 마무리되지 않는다.
- `features/campus/focus-repository.ts`, `focus-handler.ts`, `/api/campus/focus`: 활성 회원·본인 수강권 확인 후 읽기/쓰기. 시작은 현재 공개 수업 버전을 재확인하며, 기수별 진행 중 실행은 하나만 허용한다. 동일 요청 재전송은 중복 생성하지 않고, 다른 창의 오래된 수정은 충돌로 처리한다.
- `features/campus/ui/focus-panel.tsx`, `focus-client.ts`: 기존 수업 화면 이동, 실행 시작/중지/복귀, 결과 기록. 타이머는 브라우저에서 계산하며 정기 서버 폴링을 하지 않는다. 서버 읽기는 기록을 열거나 다시 확인할 때, 쓰기는 명시적인 시작·중지·복귀·마무리 때만 한다.
- 실제 회원 모드의 메모는 서버 경로만 사용하고 localStorage에 저장하지 않는다. 현재 **가상 미리보기**는 사용자·기수별 localStorage에 가장 최근 기록 하나만 보관한다. 가상 화면을 실 DEV 저장 성공으로 간주하지 않는다.
- 서버는 마무리된 기존 행을 보존한다. 이번 UI는 최근 기록만 보여주며 전체 실행 이력 탐색은 아직 없다. 입력 중 메모는 저장 버튼을 누르기 전까지 저장된 기록이 아니다.
- 수업 내용/공개 상태/삭제가 바뀌어도 본인의 실행 메모는 보존하고 마무리할 수 있다. 비공개 수업 내용은 이 경로에서 조회하거나 노출하지 않는다. 수강권 만료·회수 후에는 해당 실행 기록 경로의 접근을 차단한다.
- 수업 하드 삭제가 커리큘럼 저장을 막지 않도록 수업 ID에는 FK를 걸지 않고, 시작 시 RLS로 수업·기수·버전을 검증한다. 계정/수강권을 명시적으로 하드 삭제하면 그 개인 실행 기록도 함께 삭제한다.

개인 실행 메모·목표 타이머이며 집중 시간 인증, 수업 완료, 과제 승인, XP, 로켓 발사 자격이나 매출 성과로 환산하지 않는다. 관리자 대시보드에 개인 메모를 공개하지 않는다. 실제 고객 개인정보를 적지 않도록 안내한다.

### 미적용 SQL과 검수 경계

로컬 후보 SQL: `supabase/migrations/20261102114237_edu_campus_focus_sessions.sql`.

API는 `EDU_CAMPUS_ENABLED=true`와 **`EDU_CAMPUS_FOCUS_ENABLED=true` 두 값이 모두 있어야** 열린다. 후자는 신규 별도 기본 OFF 스위치다. 실제 DEV·운영 DB, 환경변수, 배포, 기존 수업/학생 데이터는 이번 작업에서 변경하지 않았다.

SQL은 로컬 PGlite의 최소 스키마에서 본인 접근·타인 거부·동시 실행 제한·불변 기록·수업 삭제 후 보존 등을 확인했다. **실제 기존 DB의 모든 정책과 합친 RLS 검수는 아직 하지 않았다.** DEV 적용 전에 대상·기존 스키마·공유 QA 일정과 승인 범위를 확인해야 한다. 적용 후 되돌릴 때는 스위치를 먼저 끄고 생성된 개인 메모를 보존하며, 데이터가 있는 테이블을 자동 삭제하지 않는다.

검수 결과: 관련 순수 로직·가상 HTTP/DB·PGlite·기존 접근 규칙94건, PC/모바일 브라우저18건, 변경 파일 ESLint, 전체 TypeScript 및 Next.js 프로덕션 빌드 통과. 브라우저에서는 저장/복귀 흐름, 긴 문장 레이아웃, 두 창 충돌, 시간 종료 시 자동 달성 없음, 기존 대시보드 동작을 확인했다. 실제 부하·실 DEV·원격 CI·운영 회귀는 별도 단계다.

윤익님 합본의 3D 공간·캐릭터·카메라와 첫 ZIP은 변경하지 않았다. 합본은 EDU 호스트의 이 패널을 열거나 같은 회원/기수 문맥으로 기능을 연결하면 된다. 현재 데모 타이머/XP를 이 서버 기록으로 자동 이관하지 않는다.
