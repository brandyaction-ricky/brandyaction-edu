# Brandy Edu · Brand redesign audit

2026-09-11 · 기존 25개 고객/LMS 화면 + 22개 관리자 화면 보존 · HTML 시안 전용

## 확인한 문제와 설계 결정

| 영역 | 기존 시안에서 확인한 문제 | 개선 방향 / 보존할 기능 |
|---|---|---|
| 공통 | 10–51px의 개별 글자 크기, 반복 추가된 모바일 CSS | 의미 기반 타입과 간격 토큰, 고객/운영 레이아웃을 각 한 스타일 진입점으로 통합 |
| 홈 | 온화한 베이지 톤과 설명형 히어로, 모집 상품 위계 약함 | 검정 히어로 + 현재 무료 Offer + 한 개의 강한 CTA. 유료 과정과 실행 경험을 순서대로 연결 |
| 클래스 | 콘텐츠·가격·일정의 구분이 시각적으로 약함 | 과정 정보와 결제 결정을 분리. 모집 기수·일정·가격은 같은 구매 블록 안에서 확인 |
| 무료 상세 | 이미 확정된 단순 구조 | 이미지/콘텐츠 → 자료 다운로드 → 하단 고정 CTA를 그대로 보존 |
| 아티클 | 배너·본문·영상 영역의 타입과 여백 편차 | 무료강의 상단은 독립 전환 영역, 본문은 720px 읽기 폭. 비회원/회원 상태와 3강 선택 유지 |
| 마이페이지 | 작은 통계 카드가 다음 학습보다 먼저 등장 | 이어서 학습을 첫 콘텐츠로, 학습·미션·레벨의 차이를 유지. 통계는 보조 정보로 이동 |
| 학습실 | 판매용 헤더와 푸터가 학습 흐름을 함께 차지 | 학습 전용 헤더, 강의·자료·퀴즈·미션·이전/다음에 집중. 학습 로직 변경 없음 |
| 결제 | 모바일에서 동의와 결제 블록이 신청 정보보다 먼저 표시 | 상품 → 신청자 → 쿠폰 → 수단 → 금액·동의·CTA의 DOM 읽기 순서 회복 |
| 관리자 | 작은 보조 텍스트와 상태 버튼, 다양한 입력/버튼 크기 | 기본 16px·표/보조 14px, 44px 작업 버튼, 중립 표면과 명확한 선택 행. 모든 메뉴/필터 유지 |
| 모바일 표 | 많은 열을 그대로 축소하면 정보·터치가 불안정 | 일반 표는 필드 라벨이 있는 카드, 30일 미션 매트릭스는 주차별 가로 스크롤·고정 회원 열 |

## 페이지별 UX 판단

| 페이지 군 | 가장 먼저 / 주요 행동 | 보조 행동 | 확장·모바일 판단 |
|---|---|---|---|
| 홈/탐색 | 배울 결과와 현재 참여 가능한 제안 / 무료 클래스 보기 | 유형 필터, 유료 과정 탐색 | 검색·유형 필터 유지, 모바일 한 열 |
| 무료 상세 | 상세 콘텐츠 / 신청 CTA | 사전 자료 다운로드 | 추가 탭·결제 패널 없음, 하단 CTA 안전 영역 |
| 유료 상세 | 해결할 문제·얻을 결과 / 수강 신청 | 커리큘럼·강사·후기·이용 안내 | 모바일 구매 버튼 접근성, 내용보다 먼저 결제시키지 않음 |
| 아티클 | 무료강의 선택 또는 글 제목 / 읽기·시청 | 회원가입 후 무료 3강 | 본문 내 CTA 반복 금지, 영상 비율 유지 |
| 계정/학습 | 다음 학습·해야 할 미션 / 학습 이어가기 | 일정·피드백·자료·주문 | 학습 전용 탐색, 판매 제안 최소화 |
| 미션 | 목표·마감·현재 상태 / 작성·보완 제출 | 자료·제출 기록 | 상태를 색상과 텍스트 함께 표시, 입력 내용 유지 |
| 관리자 목록 | 대상 상품·상태·필터 / 검토·편집 | 일괄 작업·상세·내보내기 | 기존 검색/필터/페이지 이동 보존. 대량 데이터의 서버 처리는 이번 범위 밖 |
| 관리자 편집 | 필수 입력·공개 상태 / 저장 | 미리보기·취소·목록 | 모바일 단일 열과 저장 액션. 실제 저장/공개는 연결하지 않음 |

## 검증 범위

이 문서는 코드·템플릿 감사에서 확인한 설계 판단입니다. 전환율 상승이나 5초 이해 여부를 실험으로 검증했다고 주장하지 않습니다. 실제 사용자 평가와 운영 데이터 연결은 디자인 승인 이후 별도 단계입니다.
