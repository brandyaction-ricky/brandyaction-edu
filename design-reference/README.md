# Brandy Edu — Brand UI/UX Final

브랜디액션의 실행·성과 중심 브랜드를 반영한 오프라인 HTML 시안입니다.

## 열어보기

- 고객 화면: frontend/brandy-frontend-final.html
- 관리자: admin/brandy-admin-uiux-v2.html
- 디자인 시스템: design-system.html
- 대표 화면별 HTML: frontend 25개 / admin 22개

HTML을 브라우저에서 열면 페이지 선택이나 메뉴를 통해 같은 파일 안에서 이동할 수 있습니다. ZIP 안에서는 상대 경로 자산을 쓰므로 압축을 푼 폴더 구조를 유지해 주세요. 별도로 제공한 통합 HTML은 자산이 포함되어 독립적으로 열 수 있습니다.

## 디자인 변경

- 공통: Black / White / Neutral + Action Red, 의미 기반 글자 크기, 4px 간격 체계, 44px 이상 주요 작업 버튼, 48px 입력창.
- 홈: 결과 중심 메시지 → 현재 모집 제안 → 무료/유료/자료 상품 → 학습 방식 → 아티클 → 고객 이야기 → 최종 CTA.
- 무료 상세: 등록된 상세 이미지 → 무료 자료 → 하단 고정 CTA 구조 보존.
- 유료 상세: 문제 → 얻을 역량 → 학습 방식·커리큘럼 → 후기 → 강사 → 안내. 가격·기수·일정은 구매 블록에서 확인.
- 아티클: 텍스트·영상, 상단 무료 3강, 가입 전/후 상태와 관리자 배너 설정 유지.
- 마이페이지: 이어서 학습을 통계보다 먼저, 미션·피드백·레벨·일정 연결. 학습 영역은 전용 헤더와 간결한 푸터.
- 관리자: 22개 화면과 카테고리 유지. 상품/유형/클래스/기간 필터, 검토·편집·일괄 작업 유지. 일반 표는 모바일 라벨 카드, 미션 매트릭스는 가로 스크롤.
- 결제: 모바일에서 상품·신청자·쿠폰·수단 확인 후 금액·동의·CTA가 나오는 읽기 순서.

## 유지한 관리자 카테고리

클래스 관리: 상품 / 기수·회차 / 학습 콘텐츠 / 미션 / 회원 미션 / 제출물 검토 / 질문함

고객 관리: 회원 / 고객 태그 / 쿠폰 / 상품 후기

콘텐츠 관리: 메인 배너 / 아티클 / 고객 후기

매출 관리: 주문 결제

마케팅 관리: 랜딩 성과 / 실측 입력 / 검색코드 / 운영·트래킹 설정

## 반응형 기준

| 구간 | 주요 전략 |
|---|---|
| Desktop > 1024px | 1248px 고객 폭, 고정 관리자 탐색, 상세 + 구매 영역, 학습 목록 + 콘텐츠 |
| Tablet 681–1024px | 간격 축소, 복잡한 상세/결제 단일 열, 계정 메뉴 가로 탐색 |
| Mobile ≤ 680px | 16px 좌우 여백, 상품 한 열, 입력/CTA 터치 크기 유지, 영상 비율 유지, 표 라벨 카드 |
| Admin ≤ 720px | 펼침 메뉴, 일반 표 카드, 매트릭스 고정 회원 열, 편집 단일 열 |

## 기능·검수 범위

이 파일은 디자인 검토용입니다. 신청·로그인·결제·승인·공개·저장은 브라우저 안의 예시 동작이며 새로고침하면 초기화됩니다. 실제 결제·회원 데이터·추적 코드를 실행하거나 배포하지 않았습니다. 무료 자료는 화면 흐름 확인용 HTML 워크시트입니다.

JavaScript 구문, 25개 고객 화면과 22개 관리자 화면의 템플릿, 상태별 화면, 메뉴·동작 연결 및 반응형 CSS 계약을 검사했습니다. 실제 브라우저 화면 검수는 이 환경의 정적 HTML 미리보기 미지원으로 수행하지 못했습니다. 실제 기기에서의 픽셀·줄바꿈·키보드/보조기기 QA와 사용자 전환 테스트는 별도 확인이 필요합니다.

브랜드 디자인 시스템을 공유하되, 기존 업무·인증·결제·콘텐츠 상태 로직은 유지했습니다. 감사 결과는 UX-audit.md, 테스트 결과는 qa-report.json에 있습니다.

## 소스

source/shared: 색상·타입·간격 토큰과 공통 컴포넌트

source/frontend/src/experience.css: 고객·학습 영역의 목적별 레이아웃

source/admin/src/interface.css / experience.css: 운영 레이아웃과 반응형 패턴

node source/frontend/build.mjs 및 node source/admin/build.mjs로 각각 단독 HTML을 다시 만들 수 있습니다. 외부 패키지 설치가 필요하지 않습니다.
